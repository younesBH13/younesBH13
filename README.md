- 🔒 **Private & Offline RAG:** Zero-cloud-leak document intelligence systems with ChromaDB, LangChain, and page-level source citations.
- 💻 **Full-Stack SaaS Engineering:** Production-grade web apps using Next.js 15 App Router, React 19, TypeScript, Tailwind CSS, and Supabase.
- 🔬 **Computer Vision & Information Retrieval:** Neural dense search (SPECTER), Truncated SVD/LSI, and industrial NDT defect detection pipelines.
